# Patient-Risk-Identificaation-via-Machine-Learning
# Disease Prediction System

## Overview

This project is a Machine Learning based Disease Prediction System developed using Python and Jupyter Notebook. The system predicts diseases based on symptoms provided by the user.

## Files Included

* `Disease.csv` → Dataset used for training and testing
* `lr_classifier.pkl` → Trained Logistic Regression model
* `ML DIASEASE PREDICTION.ipynb` → Jupyter Notebook containing model training and prediction code

## Technologies Used

* Python
* Jupyter Notebook
* Machine Learning
* Logistic Regression

## Features

* Predicts diseases based on symptoms
* Uses trained machine learning model
* Data preprocessing and model training included
* Simple and beginner-friendly implementation

## Machine Learning Workflow

1. Data Collection
2. Data Preprocessing
3. Model Training
4. Disease Prediction
5. Result Evaluation

## Dataset Information

The dataset contains:

* Symptoms
* Disease labels
* Medical-related input features used for prediction

## Skills Demonstrated

* Machine Learning
* Data Preprocessing
* Model Training
* Predictive Analysis

## How to Run

1. Open the Jupyter Notebook
2. Install required Python libraries
3. Run all notebook cells
4. Input symptoms to get predictions
